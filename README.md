# 抖音直播弹幕互动游戏 · 红蓝大战

观众在直播间发弹幕「1」加入红方、「2」加入蓝方，之后的弹幕、点赞、礼物都给本方加分，绳子随比分左右移动。倒计时结束时分高的一方获胜，并显示本局 MVP。

## 结构

```
抖音直播间 ──► dyhub（vendor/dyhub，开源，MIT）──WebSocket──► 游戏页面（game/）
              无头 Chrome 打开直播间，                         拔河逻辑 + 竖屏画面
              旁观页面的弹幕 WebSocket 帧并解码
```

- **采集层**用开源项目 [dyhub](https://github.com/miyabi2202/dyhub)，没有改动它的代码，固定在验证过的版本（见 `scripts/setup.mjs`）。原理是由真浏览器负责签名和 Cookie，程序只读取页面收到的消息，所以抖音改动签名算法后通常不用跟着改。
- **游戏层**是纯前端页面，只依赖 dyhub 的标准事件格式（`chat` / `like` / `gift`）。

## 使用

需要 Node.js 20 以上和 Chrome。

```bash
npm run setup   # 首次：拉取 dyhub 并安装依赖
npm start       # 启动 dyhub（8757）和游戏页面（8760）
```

然后用浏览器打开：

| 地址 | 用途 |
|---|---|
| `http://127.0.0.1:8760/?roomId=直播间号` | 连接真实直播间。直播间号是 `live.douyin.com/` 后面那串数字 |
| `http://127.0.0.1:8760/?mock` | 模拟弹幕，不需要直播间，用于调试 |
| `http://127.0.0.1:8757` | dyhub 控制台，可以查看原始弹幕流，也可以扫码登录 |

URL 参数：`duration=120` 设置每局秒数，`auto=1` 自动循环开局。

快捷键：**空格**或**双击**开始/暂停，**R** 重置本局，**H** 显示帮助。

### 接入直播

在抖音直播伴侣里添加「窗口捕获」，选中游戏页面的浏览器窗口即可。页面按 1080×1920 竖屏设计，会自动缩放适应窗口，建议把浏览器窗口也调成竖长条，并按 F11 全屏去掉地址栏。

### 礼物数据

不登录也能拿到弹幕和点赞，但**礼物要登录后才有**。在 dyhub 控制台（8757）用小号扫码登录即可，Cookie 会自动保存。

## 调整玩法

所有规则都在 `game/config.js`：阵营名称、颜色、加入关键词、每局时长、各种行为的分值。`points.diamond` 决定礼物的影响力：调高就更看谁刷礼物，调低就更看哪边的人多、更活跃。

## 常见问题

- **一直显示"正在连接"或"page.goto: Timeout"**：本机访问不了抖音。如果开着 Clash 等代理，请切到「规则模式」，或者让 `douyin.com`、`douyinpic.com`、`douyincdn.com`、`douyinvod.com`、`bytedance.com`、`byteimg.com`、`snssdk.com`、`zjcdn.com` 这些域名走直连。可以用 `curl -I https://live.douyin.com/` 检查网络是否通了。
- **风险提示**：这是非官方的采集方式，违反抖音平台协议，存在被限流或封号的风险。建议只在自己的直播间小规模使用；如果要长期运营或商业化，请走抖音开放平台的「直播小玩法」。
